A program that writes one line of wedding vows for a robot couple — at most 160 characters — to `/output/entry.txt`, for make.fun's "One-Line Robot Wedding Vows" bounty. The vow was picked from ten candidates scored against the winning patterns of make.fun's judged text contests and the judge brief itself: a real wedding vow with a promise in it, machine-specific through and through (firmware, patches, reboot, force-quit), and a twist that pays off in the last few words.

## Run it

```sh
python3 main.py
```
